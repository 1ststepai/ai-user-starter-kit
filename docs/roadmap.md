# Three questions. One first week.

No account. Pick one answer per question. Then copy the skill and run it once.

## 1. What are you trying to do this week?

- **Learn to steer an AI in a project** → [First-week playbook](first-week-playbook.md) + [skill-maker](../skills/skill-maker/SKILL.md)
- **Clean up files without wrecking them** → [file-organizer](../skills/file-organizer/SKILL.md)
- **Know what to do on Monday** → [weekly-brief](../skills/weekly-brief/SKILL.md)
- **Make a page easier for AI answers to quote** → [geo-block](../skills/geo-block/SKILL.md)

## 2. Which tool do you already have open?

- **Chat only** (ChatGPT / Claude.ai / Gemini in the browser) → paste the skill into the chat and say "follow this skill."
- **IDE agent** (Cursor or similar) → copy the skill folder to `.cursor/skills/<name>/`.
- **Terminal agent** (Claude Code / Codex) → copy to `.claude/skills/` or `.agents/skills/`.

One tool this week. Do not install three.

## 3. How risky is the first task?

- **Easy to undo** (draft, rename plan, brief) → run locally. If you use [Auto Model Router](https://github.com/1ststepai/auto-model-router), expect `fast / local`.
- **Sends, pays, deletes, or production** → stop. Read [safety](safety-and-trust.md). Do not auto-continue.
- **Long job you will not watch** → still confirm first. Mode `cloud` is advice, not a launch button.
