# AI User Starter Kit

_Last reviewed: September 2026._

A free first-week guide for people who just started coding with AI.

Pick one tool. Ship one small project. Learn the habits that keep you safe and in control.

No signup. No sales call. Read it in a sitting, use it for a week.

Built by [1stStep.ai](https://1ststep.ai).

## Read in order

1. [Starter map](starter-map.md) — which *kind* of tool for which job (brand names dated)
2. [First-week playbook](first-week-playbook.md) — one project and a daily loop
3. [Usage hygiene](usage-hygiene.md) — cost, secrets, and when to slow down
4. [Safety and trust](safety-and-trust.md) — treat every answer as a draft

The [GitHub README](https://github.com/1ststepai/ai-user-starter-kit) is the same landing page if you prefer to read it in the repo.

## Living kit

The guides stay markdown. The tool map is a published catalog you can pull again later — not a frozen PDF.

Each major page has a **Last reviewed** date. Stale names? [Open an issue](https://github.com/1ststepai/ai-user-starter-kit/issues). See [What’s updated](CHANGELOG.md).

```bash
python3 scripts/update-kit.py
```

1stStep updates `data/catalog.json` on `main`. That command fetches it (this repo’s GitHub raw only) and refreshes the starter-map examples.

## How to use this

1. Skim the starter map and pick **one** primary tool.
2. Follow the playbook for seven days on a throwaway project.
3. Keep the hygiene and safety pages open when you start using real keys or git.

You do not need to finish every page before you type your first prompt.
