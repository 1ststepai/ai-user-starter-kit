# How this kit fits the rest of 1stStep

The starter kit stays **free**. That is the point.

```text
Week-one humans  →  this kit + four skills
People who keep going  →  Auto Model Router (still free, confirm-gated)
People who want company  →  CodeFriends (optional community)
Teams who want memory + routing in every repo  →  1stStep OS / agent-memory
```

## What is free on purpose

- This kit and the four skills (copy-paste, no account)
- Auto Model Router skill on GitHub
- Repo Next Steps checklist

Paid should never be "the same markdown behind a login." That is how $97 courses rot.

## What can be paid later without breaking trust

1. **CodeFriends** — presence and DMs for people already in Cursor/Claude/Codex. Free for individuals at first. Charge when there is a *hosted* room, team SSO, or a school/company workspace. The kit invite stays optional.
2. **Hands-on setup** — one hour wiring AMR + skills into *their* repo. That is service, not a paywalled PDF.
3. **Team pack** — private tier maps, usage hygiene for a company Cursor/Codex bill, 1stStep OS memory that stays on their disk.
4. **GEO / Rank products** — Real-Rank and growth-finder can sell *measurement* (did the answer block get cited?). The geo-block skill itself stays free.

## What not to sell

- Comment-gated skills ("drop SKILL UP")
- A second copy of AMR text as a course module
- Cloud-agent minutes you do not control (Cursor and Codex already bill those)

## Rule of thumb

If a beginner can finish it in the first week from this repo alone, it stays free. If they need a running service, a shared room, or someone on a call, that can cost money.
