AI User Starter Kit

A free first-week guide for people who just started coding with AI.

Pick one tool. Ship one small project. Learn the habits that keep you safe and in control.

No signup. No sales call. Read it in a sitting, use it for a week.

Built by 1stStep.ai.

What’s inside

Four short pages. Read them in order, or jump to the one you need.

  1. Starter map — chat vs IDE agent vs terminal agent vs image. Categories first; brand names are examples as of a month.
  2. First-week playbook — one small project, better prompts, when to read the diff, when to restart the chat.
  3. Usage hygiene — tokens and cost without the scare story; secrets; production; verify before you commit.
  4. Safety and trust — models invent things; never paste API keys; review changes; treat output as a draft.

You do not need prior jargon. Where we use a term (diff, agent, tokens), the page defines it once.

Living kit

This is versioned markdown we update as tools and models change — not a one-shot PDF that goes stale.

Each major guide has a Last reviewed date. Brand names are examples as of that month, not a forever endorsement list.

If a tool name looks wrong, open an issue or a small PR. See What’s updated.

Keep it current

Tool categories and dated examples live in data/catalog.json. When 1stStep publishes a newer catalog on main, pull it with one command (Python 3, no packages):

python3 scripts/update-kit.py

That fetches only this repo’s GitHub raw catalog, overwrites the local file if newer, refreshes the starter-map example table, and prints what changed.

Publish path for 1stStep: edit data/catalog.json on main, bump version and updatedAt, run python3 scripts/update-kit.py --local, add a line to docs/CHANGELOG.md. Future: richer sources. v1 does not scrape vendor docs.

Who this is for

You installed a chat, an IDE agent, a terminal agent, or something like them, and you want a calm first week — not a feed of “must-use” extensions.

This kit is not a product pitch, a course, or a reason to hire anyone. It is a map and a practice loop.

How to start (10 minutes)

  1. Open the starter map and choose one tool you already have.
  2. Create a throwaway folder. Tell the AI that folder is the only place it may edit.
  3. Follow day 1 — a “hello” you can open without the AI.
  4. Keep hygiene and safety nearby when you touch keys or git.
