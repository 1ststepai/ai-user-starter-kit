# First-week skill pack

Four copy-paste skills. No account. Works in Cursor, Claude, Codex, Gemini, or any chat that will follow a `SKILL.md`.

Install: copy the folder into `.cursor/skills/`, `.claude/skills/`, `.agents/skills/`, or `.gemini/skills/`.

1. [skill-maker](skill-maker/SKILL.md) — turn a repeat prompt into a skill
2. [file-organizer](file-organizer/SKILL.md) — propose a folder plan; do not move files until confirm
3. [weekly-brief](weekly-brief/SKILL.md) — a Monday brief for *your* work
4. [geo-block](geo-block/SKILL.md) — one quotable answer block for a page

Use [Auto Model Router](https://github.com/1ststepai/auto-model-router) if you want a suggest → confirm line first. Default these four to **fast / local** unless the task is high-risk.

These skills are free. CodeFriends and paid setup help are optional later — see [docs/how-this-fits.md](../docs/how-this-fits.md).
